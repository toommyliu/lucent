title: Using Lucent
description: Find your way around Lucent's windows and tools.
---

Lucent is organized around game windows and a few focused tools. Use **File >
New Game Window** to open another client, or **File > Open Account Manager** to
launch several accounts together.

## Game window

The game window places Lucent's controls above the AQW client:

- **Windows** opens the [companion tools](#companion-tools) connected to this
  client.
- **Scripts** manages and runs your scripts & packages.
- **Options** contains client controls.
- The remaining controls handle automation (Auto Zone, Auto Relogin, Auto Attack), travel controls, and the bank shortcut.

Most controls become available after the player is logged in and ready.

### Companion tools

Companion tools open from **Windows** in the game window. Most belong to the
client that opened them; Combat Profiles is shared across the app.

- **Combat Profiles** defines shared combat behavior for all Lucent combat
  automation (Scripting, Auto Attack, Follower).
- **Environment** manages the drops, quests, and boosts Lucent should orchestrate through.
- **Follower** follows another player and acts as their combat assistant.
- **Loader/Grabber** loads game content or grabs useful game data.
- **Packets** captures, inspects, and sends game packets.

## Account Manager

The Account Manager stores accounts and launches them into separate game
windows.

## Settings

Open **Settings** from the application menu to choose the startup window,
configure updates behavior and hotkeys, or customize the app's visuals.
